# Legacy static service pages (archived 2026-08-29)

These six standalone HTML pages were the original service pages, served from
`public/` via `vercel.json` rewrites (`/signage` → `/signage.html`, etc.).

On 2026-08-29 they were **replaced by React Router pages** — one shared renderer
(`src/pages/services/ServicePage.tsx`) driven by `src/pages/services/serviceData.tsx` —
so every service page now shares the app's `<Navigation>` / `<Footer>` and works in
`vite dev`. The URLs are unchanged:

| URL                    | React route element                        |
|------------------------|--------------------------------------------|
| `/window-tint`         | `ServicePage data={services.windowFilm}`   |
| `/window-tint/home`    | `ServicePage data={services.residentialTint}` |
| `/window-tint/office`  | `ServicePage data={services.commercialTint}`  |
| `/storefront-graphics` | `ServicePage data={services.storefrontGraphics}` |
| `/signage`             | `ServicePage data={services.signage}`      |
| `/wayfinding`          | `ServicePage data={services.wayfinding}`   |

Crawler SEO shells for these routes are generated by `scripts/prerender-routes.mjs`.

The three remaining `window-tint/*` sub-pages (`storefront`, `security-film`,
`decorative-privacy`) are still live static HTML in `public/window-tint/` with their
own `vercel.json` rewrites — not yet converted.

Kept here for reference / copy source only. Nothing in the build reads this folder.
